| 积压与告警               | 系统 API 汇总各域状态及人工恢复资格。截图队列按状态暴露计数，轮询记录容量、尾部等待和跳过，归档健康探测对同类故障累计三次才有条件请求重启。仅确认应用日志、页面及重试入口，未发现面向外部值班系统的独立死信推送或积压阈值告警。[状态投影](../../apps/server/src/runtime/background-status.ts#L26) · [录制监测](../../apps/server/src/capture/supervisor.ts#L515) · [故障门槛](../../apps/server/src/runtime/archive-health.ts#L83)                                                                                                                                                                                           |

A2 的八项中，单库互斥运行、核心持久结果防重、连接余量及持有者死亡恢复有直接证据。全调用链绝对时限、所有下游立即取消、重试次数上限与外部死信告警均有上表所列边界。公开网络、真实录制、物理 NAS、持久高负荷和跨主机共享锁均未参与本轮实验。
