原提示词共 41 项，按 A1 至 A6 分别为 7、8、7、6、6、7 项。其中 5 项已验证、34 项有边界、2 项不适用。结构复扫覆盖最终代码 `5b31ca6a9`。浏览器首包与首屏数据取自最后一次产品改动 `db4a143b3` 的正式镜像，两者只相差一份端到端测试。以下判定针对本次 Linux 容器、单管理员、每个媒体库单写者的部署。**已验证**表示有满足本项的直接实现或实测；**有边界**表示只有部分路径满足、存在已知例外或缺少相应运行条件；**不适用**表示该前提不属于支持的部署模式。生产数据、跨主机共享文件系统和远端未取回的 Git 引用未参与验证。
